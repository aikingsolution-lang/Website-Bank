AIKing Solutions — DPDP Compliance Website

Open index.html in your browser, or serve this folder with:
  python3 -m http.server 8000
Then visit http://localhost:8000

Files: index.html, services.html, approach.html, about.html, contact.html,
styles.css, script.js.

HTML + Tailwind CSS (CDN), custom CSS and vanilla JavaScript.
Internet access loads Tailwind and Google Fonts; custom CSS includes core layout fallbacks.
No Node installation or build step is needed.

The contact form prepares a downloadable text inquiry. It does not send email,
store submissions on a server, or book appointments.
Five team profiles intentionally remain placeholders.
The readiness checklist is a discussion aid, not a compliance assessment.

Edit the HTML files directly and styles.css/script.js for design and behavior.
The optional generator/build.py regenerates dist/ from its embedded content
when run from the project folder. Do not run it after manual edits unless you
also update its content.
